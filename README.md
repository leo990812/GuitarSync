# GuitarSync

GuitarSync is a responsive guitar-tab discovery and practice workspace.

## Current MVP
- Responsive dark interface for desktop and mobile
- Search shortcuts for Songsterr, Ultimate Guitar, and Google
- Interactive TAB preview with copy action
- BPM slider and loop-mode preview
- Clear distinction between source search and verified musical accuracy

## Run locally
Open `index.html` in a modern browser. No build step is required.

## Publish with GitHub Pages
1. Open the repository Settings.
2. Select Pages in the sidebar.
3. Under Build and deployment, choose Deploy from a branch.
4. Select `main` and `/(root)`, then Save.

After deployment, the site will be available at:
`https://leo990812.github.io/GuitarSync/`

## Roadmap
- Search API integrations where permitted
- Candidate-tab comparison (tuning, chords, notes, rhythm)
- Audio analysis and confidence scoring
- Playback synchronization and section looping

Third-party tab content remains hosted by its original providers. This project links to source searches rather than copying or republishing copyrighted tablature.
